# Piezas SVG

Piezas del conjunto Maestro descargadas desde [lichess-org/lila](https://github.com/lichess-org/lila/tree/master/public/piece/maestro), creadas por sadsnake1 y distribuidas bajo [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).

Los archivos usan nombres descriptivos para que el tablero los cargue automáticamente:

- `white-king.svg`, `white-queen.svg`, `white-rook.svg`, `white-bishop.svg`, `white-knight.svg`, `white-pawn.svg`
- `black-king.svg`, `black-queen.svg`, `black-rook.svg`, `black-bishop.svg`, `black-knight.svg`, `black-pawn.svg`

El código conserva un símbolo Unicode como reemplazo temporal si falta alguna imagen.
